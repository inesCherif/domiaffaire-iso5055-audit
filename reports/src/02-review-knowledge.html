The five most important problems

  1. Broken access control (S07–S13). The API checks the role, never the owner. Any client can delete any account, edit any profile (even demote the admin), and read other clients' ID-card files and chats.
  2. Secrets in code (S04, S05). The JWT signing key is in the public repo, so tokens can be forged. Accountant sign-up is protected only by the code abcd.
  3. Password hashes exposed (S01–S03). A public endpoint lists all users with their bcrypt hash, and many responses embed full User objects.
  4. Chat service without authentication (S14). Anyone can read any room or write as anyone.
  5. Performance design (P01, P02). A scheduler reloads every deadline, with attached files, every second. Files are stored inside documents and returned in every list.
